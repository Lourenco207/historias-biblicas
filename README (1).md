## 🚀 Como usar
1. Criar uma conta no [GitHub](https://github.com).
2. Criar um novo repositório público (ex: `historias-biblicas`).
3. Fazer upload do arquivo `index.html` neste repositório.
4. Ativar **GitHub Pages** em *Settings > Pages* e escolher a branch `main`.
5. Aguardar alguns minutos até o site estar disponível no link.
